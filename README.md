# DroneShala Nepal Redesign

Premium Vite + React redesign for DroneShala Nepal.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## UI Structure

- shadcn-style UI components live in `components/ui`.
- Shared helpers live in `lib`.
- Global styles and Tailwind entrypoint live in `src/styles.css`.
